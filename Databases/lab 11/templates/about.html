About Student Vault

A simple system for storing and viewing student profile records.

What this project does

Student Vault helps manage student information in one place. It stores basic profile details such as name, major, age, and profile image, then displays those records through a clean student list and an admin panel.

Student Records

Add student details and keep them organized in the database.

Profile Images

Upload and view profile pictures with each student card.

Admin Access

Use the admin panel to see the complete profile data in table format.

This project was built as a database lab application using Flask, PostgreSQL, HTML, and CSS.
